이 챌린지는 새로운 종류의 연산인 **비트 XOR** 을 소개합니다.
산술을 하는 `add`, `sub`와 달리 `xor`는 개별 비트를 다룹니다.

`xor` 명령어는 두 값의 _배타적 논리합_ 을 계산합니다. 각 비트 자리에서 두 입력 비트 중 정확히 하나만 `1`이면 결과가 `1`, 아니면 `0`입니다.
예를 들면:

```
  01100001  (0x61, 'a')
^ 00101010  (0x2a, 42)
---------
  01001011  (0x4b, 75)
```

`0x4b ^ 0x2a` 같은 그림과 식에서 `^`는 XOR을 뜻하고, 어셈블리에서 명령어는 `xor`입니다.
문법은 `add`, `sub`와 같습니다: `xor rax, 42`.

XOR의 핵심 성질은 **자기 자신이 역연산** 이라는 것입니다. 같은 값으로 두 번 `xor`하면 원래 값이 돌아옵니다.
그래서 이런 것이 보인다면:

```
xor    BYTE PTR [rax],0x2a
cmp    BYTE PTR [rax],0x4b
```

프로그램은 입력 바이트를 `0x2a`와 XOR한 뒤 결과가 `0x4b`인지 확인합니다.
이것을 되돌리려면 목표 값을 키와 XOR하면 됩니다: `0x4b ^ 0x2a = 0x61`, 즉 `'a'`입니다.

자, 바이너리를 디스어셈블하고 XOR을 되돌려 플래그를 얻으세요!
