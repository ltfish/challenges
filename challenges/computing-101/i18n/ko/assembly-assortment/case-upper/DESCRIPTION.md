소문자로 바꿀 때는 `or`로 대소문자 비트를 켰습니다.
대문자로 바꾸는 것은 그 거울상입니다. 같은 비트를 *끄면* 됩니다.

`and`가 비트를 끄는 도구입니다. 비트를 0으로 마스킹할 때 써봤죠.
마스크의 `0`은 결과 비트를 끄고, `1`은 원래 비트를 통과시킵니다.
그러니 `0x20` 비트만 끄고 나머지는 남기려면 마스크는 `0x20`을 뒤집은 `0xDF`입니다.

```
  0110 0001   ('a', 0x61)
& 1101 1111   (0xDF: keep every bit except 0x20)
---------
  0100 0001   ('A', 0x41)
```

```
and rax, 0xDF
```

이것은 글자 하나의 대소문자 비트를 끕니다.
다만 이번에는 문자열 전체에 해야 합니다.

문자열은 메모리에 연달아 놓인 바이트들이며, 끝을 표시하는 `0` 바이트(NUL 종료 문자)로 끝납니다.
그것을 훑으려면 반복문이 필요합니다. [반복문 작성하기](/computing-101/control-flow/loop-write)에서 연습한, 맨 위로 `jmp`해 돌아가는 그 모양이죠.

그러니 반복문은 이렇습니다. 다음 바이트를 보고, NUL(`0`)이면 반복문 밖으로 점프해 끝내고, 아니면 대소문자 비트를 끄고, 그 바이트를 다시 저장하고, 다음으로 나아가 맨 위로 점프합니다.
반복문의 큰 얼개는 이렇습니다:

```
loop:
  ...
  je done
  ...
  jmp loop
done:
  ...
  ...
  ret
```

`rdi`로 소문자 ASCII 문자열의 포인터를 받아 NUL이 나올 때까지 반복하며 그 자리에서 대문자로 바꾸는 함수를 작성하세요.
반환값은 없습니다.
이름은 `str_upper`로 하고(글자 하나가 아니라 문자열 전체를 다루니까요), `.global str_upper`로 내보내세요.

공유 라이브러리로 빌드해서 채점기에 넘기세요:

```console
hacker@dojo:~$ as -o str_upper.o str_upper.s
hacker@dojo:~$ ld -shared -o str_upper.so str_upper.o
hacker@dojo:~$ /challenge/check str_upper.so
```
