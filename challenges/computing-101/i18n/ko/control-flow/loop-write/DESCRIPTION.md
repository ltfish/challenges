앞 챌린지에서는 다른 사람이 작성한 프로그램에서 반복문을 알아봤습니다.
이제 직접 작성해 봅시다.

반복문에는 세 가지 상태가 필요합니다. 지금 어디를 다루고 있는지, 얼마나 진행했는지, 그리고 언제 끝날지 판단하는 검사입니다.
문자열이라면 자연스러운 결승선은 널 종료 문자, 즉 마지막 문자 뒤의 `0` 바이트입니다.
반복문을 한 바퀴 돌 때마다 현재 바이트를 확인하고, 다음 바이트로 나아가고, 개수를 갱신하고, 뒤로 점프해 반복합니다.

`argv[1]`의 길이를 계산해서 그 길이를 종료 코드로 삼아 종료하는 프로그램을 작성하세요.
프로그램은 문자열을 한 바이트씩 살펴봐야 하고, 반복을 위해 뒤로 점프해야 합니다.

예를 들어 인자가 `pwn`이면 프로그램은 코드 `3`으로 종료해야 합니다.
인자가 비어 있으면 `0`으로 종료해야 합니다.

`/challenge/check`에 제출해서 플래그를 얻으세요!
