지금까지는 저희가 알려준 주소에서 메모리의 데이터를 불러왔습니다. 하드코딩된 주소(`133700` 같은)이거나 레지스터에 저장된 주소(`rax` 같은)였죠.
그런데 저희가 아무것도 준비해 주지 않아도 여러분의 프로그램이 이미 접근할 수 있는 메모리 영역이 하나 있습니다. 바로 **스택** 입니다.

스택은 프로그램이 임시 공간으로 쓰는, 이미 할당된 메모리 영역이며, `rsp` 레지스터(*스택 포인터*)가 그 꼭대기를 가리킵니다.
스택은 나중에 더 살펴보고, 지금 중요한 것은 이것입니다. 프로그램이 시작될 때 `rsp`는 그 프로그램에 넘어온 커맨드 라인 인자의 개수(프로그램 이름 자체를 포함해서)를 나타내는 데이터를 가리킵니다.

그래서 이렇게 실행하면:

```text
hacker@dojo:~$ /tmp/your-program hello world
```

상황은 이렇게 됩니다(주소는 예시입니다):

```text
    Address    │ Contents
  +───────────────────────+
  │ ...        │ ...      │
  +───────────────────────+
┌▸│ 1337000    │ 3        │  ◀── the argument count
| +───────────────────────+
| | 1337008    | ???      |
| +───────────────────────+
| | 1337016    | ???      |
│ +───────────────────────+
│
└────────────────────────────┐
                             │
   Register │ Contents       │
  +────────────────────────+ │
  │ rsp     │ 1337000      │─┘
  +────────────────────────+
```

`rsp`는 스택을 가리키고, 거기 있는 값은 `3`입니다. 프로그램 이름 하나, `hello` 하나, `world` 하나죠.
그림처럼 스택에는 다른 데이터도 있지만 지금은 신경 쓰지 않겠습니다!

이 챌린지에서는 `[rsp]`에서 인자 개수를 읽어 프로그램의 종료 코드로 쓰세요.
제대로 읽는지 확인하려고 여러 인자로 프로그램을 몇 번 실행해 보겠습니다!
