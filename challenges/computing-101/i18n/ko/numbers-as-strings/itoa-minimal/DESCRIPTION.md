여러분의 두 자리 `itoa`는 언제나 문자 *두 개* 를 썼습니다.
하지만 `7`은 `07`이 아니고 `0`도 `00`이 아닙니다. 수는 보통 앞자리 0 없이, 실제 자릿수만큼 적습니다.
이 레벨에서는 멋진 `itoa`로 가는 길목에서 변환 결과의 앞자리 0을 없애봅시다!

여전히 `99` 이하의 값만 다루므로 `div` 한 번이면 됩니다.
앞서처럼 10으로 나누면 몫이 십의 자리, 나머지가 일의 자리입니다.
몫이 `0`이면 십의 자리가 없는 것이므로, 앞자리 0을 버리고 나머지만 출력하면 됩니다.
예를 들면:

```
7:   7 / 10 = 0 rem 7   ->  quotient 0, so write just "7"
42:  42 / 10 = 4 rem 2  ->  quotient 4, so write "42"
```

한 가지 값은 여전히 조심해야 합니다. 바로 `0` 자신입니다.
그 몫도 `0`이지만 "아무것도" 쓰지 않는 것은 틀렸으므로, `'0'` 한 글자를 씁니다.

나머지는 같습니다.
`0`-`99` 범위의 `value`에 대해 `itoa(value, buf)`를 작성하세요. 앞자리 0 없이 10진수 텍스트를 `buf`에 쓰고, 쓴 문자 수(`1` 또는 `2`)를 `rax`로 반환하면 됩니다.

기억해 두세요!
