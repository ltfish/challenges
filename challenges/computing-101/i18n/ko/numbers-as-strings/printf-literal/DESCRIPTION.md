이미 표준 출력에 바이트를 쓸 수 있습니다.
이제 그것을 반복문에 넣어 작은 `printf` 스타일 프로그램을 만들기 시작합니다.

입력은 `argv[1]`에 담긴 **포맷 문자열** 입니다.
이 첫 레벨에는 아직 특별한 표시가 없습니다.
포맷 문자열의 모든 바이트가 평범한 텍스트이므로, 여러분이 할 일은 그 바이트들을 표준 출력에 쓰는 것입니다.

```
argv[1]:  "score: "
output:   "score: "
```

훑으면서 한 바이트씩 써도 되고, 평범한 바이트가 이어지는 구간을 찾아 한 번에 써도 됩니다.
어느 쪽이든 포맷 문자열의 NUL 바이트에 닿으면 멈추고 깔끔하게 종료하세요.

실행 파일로 빌드하고 제출하세요:

```console
hacker@dojo:~$ as -o prog.o prog.s
hacker@dojo:~$ ld -o prog prog.o
hacker@dojo:~$ ./prog 'score: '
score: hacker@dojo:~$ /challenge/check prog
```

위에서 `prog`가 끝에 널 바이트를 찍지 않아 명령 프롬프트가 같은 줄에서 시작한다는 점에 유의하세요.
괜찮습니다. 다음 레벨에서 포매터에 개행을 쓰는 법을 가르칩니다.
