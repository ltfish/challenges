이제 계산기에 곱셈을 가르쳐 봅시다!

곱셈에는 자기 명령어가 있습니다. 바로 `imul`입니다.
`'+'`에 `add`를, `'-'`에 `sub`를 썼듯이 `'*'`에는 `imul`을 씁니다.
`atoi-two-digits`에서 `imul rax, 10`으로 누적 합계를 열 배 했을 때 이미 만나봤죠. 여기서도 같은 방식으로 두 피연산자를 곱합니다.

```
"6"   ->  atoi  ->   6
"7"   ->  atoi  ->   7
6  *  7  =  42
42   ->  itoa  ->  "42"
```

연산자 바이트에 세 번째 분기를 추가하세요. `'*'`이면 피연산자를 `imul`하고, `'+'`와 `'-'`는 앞서처럼 동작하며, 다른 연산자는 여전히 0이 아닌 종료 코드로 그만둡니다.

셸과 관련한 잔주름이 하나 있습니다. `*`는 셸에서 특별한 의미(파일 이름으로 펼쳐짐)를 가지므로, 손으로 실행할 때는 따옴표로 감싸세요. `./prog 6 '*' 7`이나 `./prog 6 "*" 7`처럼요.
프로그램이 받는 문자는 여전히 평범한 `'*'`입니다.

앞서처럼 빌드하고 제출하세요:

```console
hacker@dojo:~$ as -o prog.o prog.s
hacker@dojo:~$ ld -o prog prog.o
hacker@dojo:~$ ./prog 6 '*' 7
42
hacker@dojo:~$ /challenge/check prog
```
