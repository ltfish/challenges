리터럴 출력, 개행 이스케이프, 이스케이프된 문법 문자로 훑고 쓰는 반복문이 갖춰졌습니다.
이제 첫 번째 표시인 `%d`를 추가합니다.

`%` 바이트는 "이것은 표시다"라고 말합니다.
`d` 바이트는 "다음 인자 값을 가져와 부호 있는 10진수로 다뤄 여기에 그 수를 출력하라"고 말합니다.
다음 커맨드 라인 값은 `argv[2]`에서 시작합니다.

```
argv[1]:  "value=%d"
argv[2]:  "-42"
output:   "value=-42"
```

훑다가 `%d`에 닿으면 표시 두 바이트를 건너뛰고, 다음 `argv` 문자열을 `atoi`로 변환하고, 그 결과 수를 부호 있는 `itoa`로 다시 텍스트로 바꿔 그 숫자들을 곧바로 `write`하세요.
그런 다음 포맷 문자열 훑기를 이어가세요.
이 레벨에서 포맷 문자열에는 `%d` 표시가 많아야 하나입니다.
평범한 텍스트와 `\n`, `\\`, `%%`도 앞서처럼 계속 처리해야 합니다.

앞서처럼 빌드하고 제출하세요:

```console
hacker@dojo:~$ as -o prog.o prog.s
hacker@dojo:~$ ld -o prog prog.o
hacker@dojo:~$ ./prog 'value=%d' -42
value=-42
hacker@dojo:~$ /challenge/check prog
```

훑으면서 10진수 표시를 바꿔치기하세요.
