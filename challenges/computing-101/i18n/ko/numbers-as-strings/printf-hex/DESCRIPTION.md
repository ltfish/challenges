`\n`은 이름 붙은 ASCII 바이트 하나, 즉 개행 `0x0a`를 줍니다.
임의의 바이트를 쓰려면 16진 이스케이프 `\xNN`을 씁니다.

16진수는 앞에서 봤습니다. 16진수 두 자리가 한 바이트를 나타내죠.
여기서는 `\x`가 이스케이프를 시작하고, 그다음 16진수 두 자리가 쓸 바이트 값입니다.

```
format bytes:  "\x41"
hex value:      0x41
output byte (ascii):    "A"
```

변환 단계를 조심하세요. 포맷 문자열에는 아직 숫자로서의 16진 값이 아니라 ASCII 문자가 들어 있습니다.
`\x4a`라면 프로그램이 보는 것은 백슬래시, `x`, `4`, `a` 네 바이트입니다.
`\x`를 알아본 뒤의 변환은 `4`와 `a`의 ASCII 바이트를 씁니다.
먼저 각 ASCII 16진 문자를 4비트 수, 즉 니블로 바꾸세요.
`0`부터 `9`까지는 `0`의 ASCII 값을 빼면 `0`부터 `9`가 나옵니다.
`a`부터 `f`까지는 `a`의 ASCII 값을 빼고 `10`을 더하며, `A`부터 `F`까지는 `A`의 ASCII 값을 빼고 `10`을 더합니다.
그런 다음 첫 니블을 바이트의 상위 절반에(앞에서 배운 왼쪽 시프트를 쓰세요!), 두 번째 니블을 하위 절반에 넣습니다: `(첫째 << 4) | 둘째`.

```
format text:      \ x 4 a
hex digits:           4 10
combined byte:        (4 << 4) | 10 = 0x4a
output byte:          "J"
```

훑다가 `\xNN`을 보면 16진수 두 자리를 한 바이트로 바꿔 그 바이트를 `write`하세요.
평범한 텍스트와 `%d`, `%s`, `\n`, `\\`, `%%`도 계속 지원해야 합니다.

앞서처럼 빌드하고 제출하세요:

```console
hacker@dojo:~$ as -o prog.o prog.s
hacker@dojo:~$ ld -o prog prog.o
hacker@dojo:~$ ./prog 'byte=\x2a'
byte=*
hacker@dojo:~$ /challenge/check prog
```

16진 바이트 이스케이프를 디코딩해서 쓰세요.
