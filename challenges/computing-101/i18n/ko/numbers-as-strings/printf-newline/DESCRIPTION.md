리터럴 출력은 눈에 보이는 문자를 그대로 복사할 수 있지만, 텍스트에는 직접 입력하기 곤란한 바이트를 가리키는 방법도 필요합니다.
개행이 대표적인 예입니다. 눈에 보이는 기호를 그리는 대신 터미널을 다음 줄로 옮기죠.

ASCII는 앞에서 봤습니다. 텍스트 문자와 텍스트 제어에 바이트 값을 할당하죠.
ASCII 개행 바이트는 `0x0a`, 10진수로 `10`입니다.

포맷 문자열에서 특수 문자를 적는 흔한 표준은 `\` 접두사이며, 개행은 `\n`으로 적습니다.
이 레벨에서 포맷 문자열의 두 입력 바이트 `\n`은 "값이 `0x0a`인 출력 바이트 하나를 쓰라"는 뜻입니다.
백슬래시가 **이스케이프 시퀀스** 를 시작하고, 그다음 바이트가 어떤 특수 바이트를 쓸지 알려줍니다.

```
argv[1]:  "hello\nworld"
output:   "hello"
          "world"
```

훑다가 백슬래시 뒤에 `n`이 오는 것을 보면 두 바이트를 건너뛰고 값이 `0x0a`인 바이트 하나를 `write`하세요.
평범한 텍스트도 계속 지원해야 합니다.

직접 시험해 볼 때, 어떤 셸 문법은 프로그램이 보기 전에 `\n`을 해석할 수 있다는 점을 조심하세요.
프로그램이 `\`와 `n` 두 바이트를 받도록 포맷 문자열을 작은따옴표로 감싸세요. `./prog 'hello\nworld'`처럼요.

앞서처럼 빌드하고 제출하세요:

```console
hacker@dojo:~$ as -o prog.o prog.s
hacker@dojo:~$ ld -o prog prog.o
hacker@dojo:~$ ./prog 'hello\nworld'
hello
world
hacker@dojo:~$ /challenge/check prog
```

`\n`을 개행 바이트로 바꾸세요.
