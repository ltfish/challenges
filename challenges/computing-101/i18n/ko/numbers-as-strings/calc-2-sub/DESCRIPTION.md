이제 계산기에 뺄셈을 가르쳐 봅시다!

연산자 바이트에 두 번째 분기를 추가하세요. `'-'`이면 더하는 대신 왼쪽 피연산자에서 오른쪽 피연산자를 `sub`하면 됩니다.
그 밖에는 이미 작성한 분기와 같습니다. `'+'`는 더하고, `'-'`는 빼고, 다른 연산자는 여전히 0이 아닌 종료 코드로 그만둡니다.

한 가지 주의할 점은 차가 **음수** 일 수 있다는 것입니다.

```
"3"   ->  atoi  ->   3
"10"  ->  atoi  ->  10
3  -  10  =  -7
-7   ->  itoa  ->  "-7"
```

그것은 여러분의 부호 있는 `itoa`가 이미 처리하는 경우입니다. 앞의 `'-'`와 크기를 알아서 써 주니까요.
그러니 차를 지금까지 쓰던 그 `itoa`에 그대로 넣으면 부호는 알아서 처리됩니다.

앞서처럼 빌드하고 제출하세요:

```console
hacker@dojo:~$ as -o prog.o prog.s
hacker@dojo:~$ ld -o prog prog.o
hacker@dojo:~$ ./prog 3 - 10
-7
hacker@dojo:~$ /challenge/check prog
```

뺄셈 분기를 추가하고 부호가 붙은 결과를 출력하세요.
