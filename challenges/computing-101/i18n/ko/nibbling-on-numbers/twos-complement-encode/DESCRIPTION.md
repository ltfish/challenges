앞의 세 레벨에서는 비트를 부호 있는 수로 _읽었습니다_. 이제 반대로 가봅시다. 어떤 수가 주어지면 그것의 2의 보수 비트를 **써야** 합니다.

0 이상인 수라면 그냥 평범한 2진수를 앞에 0을 채워 바이트를 맞추면 됩니다. 음수라면 맨 첫 레벨의 규칙을 떠올리세요. 어떤 음수의 `n`비트 2의 보수 패턴은 부호 없는 수 `(값 + 2ⁿ)`과 같은 비트입니다. 한 바이트(8비트)라면 256을 더한다는 뜻이죠:

```
  -5   ->   -5 + 256 = 251   ->   11111011
  42   ->                         00101010
```

(같은 말로: `+5`의 비트를 뒤집고 1을 더해도 같은 답인 `11111011`이 나옵니다. 어느 쪽으로 생각해도 됩니다.)
