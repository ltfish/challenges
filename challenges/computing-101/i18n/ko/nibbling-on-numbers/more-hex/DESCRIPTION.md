10진수와 마찬가지로 자릿수를 얼마든지 늘려서 점점 더 많은 바이트를 나타낼 수 있습니다.
16진수 두 자리마다 바이트가 하나씩 늘어납니다.
궁금해할 분을 위해 말하자면 16진수 한 자리는 _니블(nibble)_ 이라고 부르지만(하하!), 데이터를 지정할 때는 쓰지 않습니다.
우리는 거의 언제나 그보다 작은 단위가 아니라 _바이트_ 단위로 데이터를 다룹니다.

이 챌린지에서 그것을 연습합니다.
각 바이트의 8비트를 4비트씩 두 묶음으로 나누고, 각 묶음을 16진수 한 자리로 바꾼 뒤, 바이트를 왼쪽에서 오른쪽으로 적으세요. 예를 들면:

```
1110 0011   0101 1010   1001 0000
 e    3      5    a      9    0
-> 0xe35a90
```

이제 여러분 차례입니다. `/challenge/convert`를 실행해서 플래그를 얻으세요!
