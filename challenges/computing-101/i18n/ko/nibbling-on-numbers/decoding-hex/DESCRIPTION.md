지금까지는 이진 데이터를 16진수로 **인코딩** 했습니다. 이제 반대로 **디코딩** 해봅시다. 즉 16진수를 그것이 나타내는 비트로 되돌리는 것입니다.

같은 대응을 거꾸로 적용하는 것뿐입니다.
16진수 각 자리가 자기 4비트가 되고, 그것을 순서대로 적습니다.
한 바이트는 16진수 두 자리이므로, 한 바이트를 디코딩한다는 것은 16진수 두 자리를 8비트로 펼친다는 뜻입니다:

```
0x   0      a
     0000   1010
->   00001010
```

이것이 바로 프로그램이 16진수로 인코딩된 데이터를 받았을 때 하는 일입니다. 16진수 두 자리씩을 그것이 나타내는 바이트로 되돌린 뒤에 작업하죠.
앞자리 0까지 포함해서 8비트를 온전히 적으세요. 16진수 한 자리는 언제나 정확히 4비트입니다.

`/challenge/convert`를 실행해서 플래그를 얻으세요!
