지금까지는 프로그램의 디스어셈블리에서 비밀을 읽었습니다.
그런데 비밀이 숨겨져 있다면 어떨까요?

이 레벨에서는 디스어셈블리가 **검열** 되어, 비밀 값이 `CENSORED`로 바뀌어 있습니다.
하지만 코드에서 그 값을 _읽을_ 수 없어도 코드를 _실행_ 할 수는 있습니다!
CPU가 `mov rdi, CENSORED`를 실행하면 실제 비밀 값이 `rdi` 레지스터에 들어갑니다.

GDB에서 명령어 하나를 실행하려면 `stepi` 명령(명령어 하나를 **step**, `si`로 줄여 쓸 수 있습니다)을 씁니다:

```gdb
(gdb) stepi
```

`mov` 명령어를 지나가고 나면 저희가 `rdi` 레지스터를 읽어 비밀 값을 보여드리겠습니다.
