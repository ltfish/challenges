앞 레벨에서는 여러분이 한 단계 진행한 뒤 저희가 레지스터 값을 대신 읽어 주었습니다.
이제 여러분 차례입니다!

디스어셈블리는 여전히 검열되어 있으므로 다음을 해야 합니다:
1. `starti`로 프로그램을 시작합니다
2. `stepi`(또는 `si`)로 명령어 하나를 진행합니다
3. `print $rdi`로 레지스터를 직접 읽습니다

`print` 명령은 어떤 식의 값을 보여줍니다.
GDB에서 레지스터 이름 앞에는 `$`를 붙이므로, `rdi`는 이렇게 읽습니다:

```gdb
(gdb) print $rdi
$1 = 1337
```

그런 다음 그 값을 `/challenge/submit-number`로 제출하세요.
