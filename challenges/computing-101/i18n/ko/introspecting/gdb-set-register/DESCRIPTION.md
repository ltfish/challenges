앞 레벨에서는 `print`로 레지스터 값을 읽었습니다.
GDB는 프로그램이 멈춰 있는 동안 레지스터를 바꿀 수도 있습니다.

`set` 명령은 레지스터에 새 값을 대입합니다:

```gdb
(gdb) set $rax = 42
```

`print`와 마찬가지로 레지스터 이름 앞에 `$`를 붙입니다.

이 레벨에서는 다음을 해야 합니다:

1. `starti`로 프로그램을 시작하고 첫 명령어를 지나갑니다.
2. `rdi`를 `1337`로 설정하고 한 단계 더 진행합니다.
3. 그 결과로 나온 비밀 숫자를 출력한 뒤 `/challenge/submit-number`로 제출합니다.

`gdb /challenge/debug-me`를 실행하고 레지스터를 바꿔보세요!
