알다시피 모든 프로그램은 종료할 때 _종료 코드_ 를 남깁니다.
이것은 `exit` 시스템 콜에 인자를 넘겨서 정합니다.

시스템 콜 번호(예: `exit`의 `60`)를 `rax`에 지정하듯, 인자도 레지스터로 시스템 콜에 전달합니다.
시스템 콜은 여러 개의 인자를 받을 수 있지만 `exit`는 하나만 받습니다. 바로 종료 코드입니다.
시스템 콜의 첫 번째 인자는 또 다른 레지스터인 `rdi`로 전달합니다.
이 챌린지에서 다룰 것이 바로 `rdi`입니다.

이 챌린지에서는 프로그램이 종료 코드 `42`로 끝나게 만들어야 합니다.
따라서 프로그램에는 명령어 세 개가 필요합니다:

1. 프로그램의 종료 코드를 설정합니다(`rdi`로 옮깁니다).
2. `exit` 시스템 콜의 번호를 설정합니다(`mov rax, 60`).
3. `syscall`!
