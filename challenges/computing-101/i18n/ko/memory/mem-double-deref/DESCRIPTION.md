지난 몇 레벨에서 여러분은 다음을 해왔습니다:

- 저희가 알려준 주소(한 레벨에서는 `133700`, 다른 레벨에서는 `123400`)로 메모리에서 비밀 값을 불러왔습니다.
- 저희가 `rax`에 넣어둔 주소로 메모리에서 비밀 값을 불러왔습니다.
- 저희가 알려준 주소(지난 레벨의 `567800`)로 메모리에서 비밀 값의 _주소_ 를 레지스터로 불러온 뒤, 그 레지스터를 포인터로 삼아 메모리에서 비밀 값을 가져왔습니다!

이제 마지막 두 가지를 합쳐 봅시다.
이 챌린지에서는 `SECRET_VALUE`를 메모리 주소 `SECRET_LOCATION_1`에 저장하고, 그 `SECRET_LOCATION_1`을 메모리 주소 `SECRET_LOCATION_2`에 저장했습니다.
그런 다음 `SECRET_LOCATION_2`를 `rax`에 넣었습니다!
`SECRET_LOCATION_1`을 `123400`으로, `SECRET_LOCATION_2`를 `133700`으로 두면 결과는 대략 이렇습니다(실제 챌린지에서 이 값들은 다르고 여러분에게 숨겨져 있습니다!):

```text
      Address │ Contents
    +────────────────────+
┌──▸│ 133700  │ 123400   │─┐
│   +────────────────────+ │
│ ┌▸│ 123400  │ 42       │ │
│ │ +────────────────────+ │
│ └────────────────────────┘
└──────────────────────────┐
                           │
     Register │ Contents   │
    +────────────────────+ │
    │ rax     │ 133700   │─┘
    +────────────────────+
```

여기서는 메모리 읽기를 두 번 해야 합니다. 하나는 `rax`를 역참조해서 `rax`가 가리키는 곳(`SECRET_LOCATION_2`)에서 `SECRET_LOCATION_1`을 읽는 것이고, 다른 하나는 이제 `SECRET_LOCATION_1`을 담고 있는 레지스터를 역참조해서 `SECRET_VALUE`를 `rdi`로 읽어 종료 코드로 쓰는 것입니다!
