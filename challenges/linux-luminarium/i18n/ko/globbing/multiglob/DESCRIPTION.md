지금까지는 한 번에 글로브를 하나씩만 썼지만, 더 할 수 있습니다!
bash는 한 단어 안에서 여러 글로브를 펼치는 것을 지원합니다.
예를 들면:

```console
hacker@dojo:~$ cat /*fl*
pwn.college{YEAH}
hacker@dojo:~$
```

위에서 일어나는 일은, 셸이 `/`에서 _무엇이든_ (아무것도 없어도 됩니다)으로 시작해 `f`와 `l`이 있고 _무엇이든_ (`flag`가 되게 하는 `ag`를 포함해서)으로 끝나는 모든 파일을 찾는 것입니다.

이제 직접 해보세요.
`/challenge/files`에 이름이 제각각인 즐거운 파일들을 몇 개 놓아 두었습니다.
그곳으로 `cd`한 다음, `p`라는 글자가 들어간 모든 단어를 아우르는, `*` 글로브 두 개가 들어간 짧은(3글자 이하) 글로브 단어 하나를 인자로 주어 `/challenge/run`을 실행하세요.
