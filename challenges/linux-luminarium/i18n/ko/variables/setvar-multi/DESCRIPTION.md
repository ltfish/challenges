이 레벨에서는 따옴표에 대해 배웁니다.
셸에서 공백은 특별한 의미를 가지며, 함부로 쓸 수 없는 자리가 있습니다.
변수 설정을 다시 떠올려 봅시다:

```console
hacker@dojo:~$ VAR=1337
```

이것은 `VAR` 변수를 `1337`로 설정합니다. 그런데 `1337 SAUCE`로 설정하고 싶다면 어떨까요?
이렇게 해볼 수 있습니다:

```console
hacker@dojo:~$ VAR=1337 SAUCE
```

그럴듯해 보이지만 동작하지 않습니다. `=` 주위에 공백을 두면 안 되는 것과 비슷한 이유입니다.
셸은 공백을 만나면 변수 대입이 끝났다고 보고, 다음 단어(여기서는 `SAUCE`)를 명령으로 해석합니다.
`VAR`을 `1337 SAUCE`로 설정하려면 *따옴표* 로 묶어야 합니다:

```console
hacker@dojo:~$ VAR="1337 SAUCE"
```

이제 셸은 `1337 SAUCE`를 하나의 토큰으로 읽고, 그 값을 기꺼이 `VAR`에 넣어 줍니다.
이 레벨에서는 `PWN` 변수를 `COLLEGE YEAH`로 설정해야 합니다.
