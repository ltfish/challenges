변수에 담긴 값을 읽을 수 있듯이, 당연히 변수에 값을 쓸 수도 있습니다.
다른 많은 언어와 마찬가지로 `=`로 합니다.
변수 `VAR`을 값 `1337`로 설정하려면 이렇게 씁니다:

```console
hacker@dojo:~$ VAR=1337
```

`=` 주위에 공백이 없다는 점에 주의하세요!
공백을 넣으면(예: `VAR = 1337`) 셸은 변수 대입으로 인식하지 못하고, 대신 (존재하지 않는) `VAR` 명령을 실행하려 합니다.

또한 `$VAR`이 *아니라* `VAR`을 쓴다는 점에 주의하세요. `$`는 변수에 *접근* 할 때만 앞에 붙입니다.
셸 용어로 이렇게 `$`를 붙이는 것을 *변수 확장(variable expansion)* 이라고 하는데, 놀랍게도 여러 잠재적 취약점의 근원이기도 합니다(관심이 있다면 커맨드 라인에 익숙해진 뒤 Art of the Shell 도장을 살펴보세요!).

변수를 설정한 뒤에는 앞서 배운 방법으로 접근할 수 있습니다. 예를 들면:

```console
hacker@dojo:~$ echo $VAR
1337
```

이 레벨을 풀려면 `PWN` 변수를 `COLLEGE` 값으로 설정해야 합니다.
조심하세요. 변수의 이름과 값은 모두 대소문자를 구분합니다!
`PWN`은 `pwn`과 다르고 `COLLEGE`는 `College`와 다릅니다.
