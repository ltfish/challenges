`/challenge/run` 프로그램은 플래그를 주지 않고, 줄 수도 없습니다. 하지만 괜찮습니다. 플래그가 "FLAG"라는 변수에 담겨 있으니까요!
셸로 그것을 출력하기만 하면 됩니다!

방법은 여러 가지지만, `echo`부터 시작합시다.
이 명령어는 그저 무언가를 출력합니다.
예를 들면:

```console
hacker@dojo:~$ echo Hello Hackers!
Hello Hackers!
```

변수 이름 앞에 `$`를 붙이면 `echo`로 변수도 출력할 수 있습니다.
예를 들어 현재 셸의 현재 작업 디렉터리를 항상 담고 있는 `PWD`라는 변수가 있습니다.
이렇게 출력합니다:

```console
hacker@dojo:~$ echo $PWD
/home/hacker
```

이제 여러분 차례입니다.
셸로 `FLAG` 변수를 출력해서 이 챌린지를 푸세요!
