데이터를 파이프하는 목적 중 하나는 그것을 _변형_ 하는 것입니다.
많은 리눅스 명령어가 아주 멋진 방식으로 데이터를 변형하도록 도와줍니다.
그중 하나가 `tr`인데, 표준 입력으로 받은 문자를 `tr`anslate(변환)해서 표준 출력으로 찍어 줍니다.

가장 기본적인 사용법에서 `tr`은 첫 번째 인자로 준 문자를 두 번째 인자로 준 문자로 바꿉니다:

```console
hacker@dojo:~$ echo OWN | tr O P
PWN
hacker@dojo:~$
```

여러 문자도 다룰 수 있는데, 첫 인자의 각 위치에 있는 문자가 두 번째 인자의 같은 위치 문자로 바뀝니다.

```console
hacker@dojo:~$ echo PWM.COLLAGE | tr MA NE
PWN.COLLEGE
hacker@dojo:~$
```
