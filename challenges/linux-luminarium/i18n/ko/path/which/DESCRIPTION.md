명령의 이름을 입력하면, `$PATH` 변수에 나열된 여러 디렉터리 중 어딘가에 있는 _무언가_ 가 실제로 실행됩니다(물론 그 명령이 빌트인이 아니라면요!).
그런데 정확히 _어느_ 파일일까요?
이름 그대로인 `which` 명령으로 알아낼 수 있습니다:

```console
hacker@dojo:~$ which cat
/bin/cat
hacker@dojo:~$ /bin/cat /flag
YEAH
hacker@dojo:~$
```

셸이 명령을 찾을 때 하는 일을 그대로 흉내 내어, `which`는 `$PATH`의 디렉터리를 순서대로 살펴보고 인자로 준 이름과 일치하는 첫 파일을 출력합니다.

이 챌린지에서는 `$PATH` 어딘가에 `win` 명령을 넣어 두었지만, 그것은 플래그를 주지 않습니다.
대신, 여러분이 읽을 수 있게 만들어 둔 `flag` 파일과 같은 디렉터리에 있습니다!
(`which` 명령으로) `win`을 찾아내고, 그 디렉터리에서 플래그를 `cat`하세요!
