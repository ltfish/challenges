싹 밀어버리고 처음부터 다시 시작하고 싶나요?
할 수 있습니다!

```console
hacker@dojo:~$ ls /
bin etc blah blah blah
hacker@dojo:~$ rm -rf /
hacker@dojo:~$ ls /
bash: ls: command not found
hacker@dojo:~$
```

여기서 무슨 일이 일어났을까요?
기억하듯이 `rm`은 파일을 지웁니다.
`-r`(재귀) 플래그는 디렉터리와 그 안의 모든 파일을 지웁니다.
`-f`(강제) 플래그는 `rm` 명령이 마주치는 오류나 망설임을 무시합니다.
이것들을 합쳐 `/`를 겨누면 결과는 파국적입니다. 시스템 전체가 지워지죠.
현대 시스템에서는 그렇게까지 간단하지는 않지만, 직접 해보면 알게 될 것입니다.

이 챌린지에서는 아마 다시는 하지 않을 일을 하게 됩니다. 시스템 전체를 밀어버리는 것이죠.
홈 디렉터리는 안전하도록 조금 손봐 두었지만(원래대로라면 그것도 지워집니다!), 그 밖에는 여러분과 플래그 사이를 가로막는 것은 드라이브를 밀어버릴 결심뿐입니다.
다만 전부 밀어버리기 전에 `/challenge/check`를 먼저 실행해서 불꽃놀이를 지켜보게(그리고 플래그를 주게) 하세요!
