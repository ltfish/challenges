`cat` 없이도 살 수 있군요!
그렇다면 `ls` 없이는요?
이번에는 `/challenge/check`가 플래그를 _무작위 이름_ 의 파일로 복원합니다.
`ls` 명령에 기대지 않고 그것을 찾아야 합니다.

이 챌린지를 푸는 방법은 여러 가지입니다.
`echo`는 빌트인이고, 그 인자에 [파일 글로브](/linux-luminarium/globbing)를 써서 모든 파일로 펼칠 수 있습니다!
예를 들어 `echo *`는 현재 디렉터리의 모든 파일 이름을 출력합니다.
비슷하게, 인자에 탭 자동완성을 (탭을 몇 번 눌러) 쓰면 셸이 가능한 파일들을 알려줍니다.

어떤 방법을 쓰든, `rm` 이후 `/challenge/check`가 `/`에 만든 무작위 이름의 파일을 찾아 읽고 플래그를 얻으세요!
