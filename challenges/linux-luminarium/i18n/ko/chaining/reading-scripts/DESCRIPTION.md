셸 스크립트를 쓰는 사람이 여러분만 있는 것은 아닙니다!
셸 스크립트는 간단한 "시스템 수준" 작업에 아주 편리하며, 개발자와 시스템 관리자가 흔히 손을 뻗는 도구입니다.
사실 일반적인 리눅스 머신에 있는 프로그램 중 놀랄 만큼 많은 비율이 셸 스크립트입니다.

이 레벨에서는 셸 스크립트를 읽는 법을 배웁니다.
`/challenge/run`은 비밀 비밀번호를 입력하라고 요구하는 셸 스크립트인데, 그 비밀번호가 스크립트 안에 하드코딩되어 있습니다!
(예를 들어 `cat`으로) 스크립트를 읽어 비밀번호를 알아내고 플래그를 얻으세요!

----
**참고:**
다른 챌린지의 코드도 마음껏 읽어보세요!
코드를 읽는 것은 새로운 기술을 익히는 데 아주 중요한 전략입니다. 어떤 기능이 어떻게 구현되었는지 보고 그 방법을 자기 스크립트에 다시 쓸 수 있으니까요.
다만 조심하세요. 어떤 프로그램 파일은 기계어라서 사람이 읽을 수 없습니다.
`file` 명령으로 구별할 수 있지만, 리눅스 루미나리움의 거의 모든 챌린지는 셸 스크립트로 구현되어 있어 안심하고 `cat`해도 됩니다.
