bash에서는 `if` 문으로 판단을 내릴 수 있습니다:

```bash
if [ "$1" == "ping" ]
then
    echo "pong"
fi
```

위 코드를 우리말로 옮기면 `첫 번째 인자가 "ping"이면 "pong"을 출력하라`입니다.
이 문법은 몇 가지 이유로 다소 깐깐합니다.
첫째, `if` 뒤와 `[` 뒤, 그리고 `]` 앞에 공백이 _반드시_ 있어야 합니다(C 같은 언어에 익숙하다면 다른 점입니다).
둘째, `if`, `then`, `fi`는 모두 서로 다른 줄에 있어야 합니다(또는 세미콜론으로 구분해야 합니다). 한 문장에 뭉뚱그릴 수 없습니다.
좀 별나기도 합니다. `endif`나 `end` 같은 것 대신 `if` 문의 종결자가 `fi`(`if`를 거꾸로 쓴 것)입니다.
그냥 외워야 하는 것이죠.

이 챌린지에서는 `/home/hacker/solve.sh`에 다음과 같은 스크립트를 작성하세요:

- 인자가 "pwn"이면 "college"를 출력합니다
- 그 밖의 입력에는 아무것도 출력하지 않습니다

예시:

```console
hacker@dojo:~$ bash /home/hacker/solve.sh pwn
college
hacker@dojo:~$ bash /home/hacker/solve.sh foo
hacker@dojo:~$
```
