조금 더 까다로운 것을 해봅시다!
`|`로 프로그램 사이에 출력을 파이프해 봤지만, 지금까지는 한 명령의 출력과 다른 명령의 입력 사이에서만 그랬습니다.
그런데 여러 프로그램의 출력을 한 명령으로 보내고 싶다면 어떨까요?
방법은 몇 가지 있는데, 여기서는 간단한 하나를 살펴봅니다. 바로 스크립트의 출력을 리다이렉트하는 것입니다!

셸이 보기에 여러분의 스크립트는 그저 또 하나의 명령일 뿐입니다.
즉 [파이핑](/linux-luminarium/piping) 모듈에서 명령에 했던 것처럼 스크립트의 입력과 출력도 리다이렉트할 수 있습니다!
예를 들어 파일에 쓸 수 있습니다:

```console
hacker@dojo:~$ cat script.sh
echo PWN
echo COLLEGE
hacker@dojo:~$ bash script.sh > output
hacker@dojo:~$ cat output
PWN
COLLEGE
hacker@dojo:~$
```

여러 리다이렉션 방법이 모두 동작합니다. stdout에는 `>`, stderr에는 `2>`, stdin에는 `<`, 덧붙이기 모드에는 `>>`와 `2>>`, 다른 파일 디스크립터로 보낼 때는 `>&`, 다른 명령으로 파이프할 때는 `|`입니다.

이 레벨에서는 스크립트에서 다른 프로그램으로 파이프(`|`)하는 것을 연습합니다.
실행 가능한 스크립트는 뒤에서 다루므로, 출력을 파이프할 때는 `bash`로 스크립트를 실행하세요.
앞서와 같이 `/challenge/pwn` 명령에 이어 `/challenge/college` 명령을 호출하는 `.sh` 스크립트를 만들고, 그 스크립트의 출력을 `/challenge/solve` 명령 한 번에 파이프하세요.
