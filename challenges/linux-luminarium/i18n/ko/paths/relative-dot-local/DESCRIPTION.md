이 레벨에서는 `.`으로 경로를 가리키는 연습을 조금 더 해봅니다.
이 챌린지는 `/challenge` 디렉터리에서 실행해야 합니다.
여기서 이야기가 살짝 까다로워집니다.

리눅스는 여러분이 "벌거벗은" 경로를 적었을 때 현재 디렉터리를 자동으로 뒤지는 일을 일부러 피합니다.
다음을 봅시다:

```console
hacker@dojo:~$ cd /challenge
hacker@dojo:/challenge$ run
```

이것은 /challenge/run을 실행하지 *않습니다*.
이건 사실 안전장치입니다: 벌거벗은 경로를 적을 때마다 리눅스가 현재 디렉터리에서 프로그램을 찾는다면, 마침 핵심 시스템 유틸리티와 같은 이름을 가진 현재 디렉터리의 프로그램을 실수로 실행하게 될 수도 있으니까요!
그래서 위 명령은 다음과 같은 오류를 냅니다:

```
bash: run: command not found
```

이 개념 뒤에 있는 메커니즘은 나중에 살펴보고, 이 챌린지에서는 이런 상황에서 `run`을 실행하기 위해 상대 경로를 명시적으로 쓰는 법을 배웁니다.
방법은 앞 레벨들에서처럼 `.`을 써서, 현재 디렉터리에 있는 프로그램을 실행하겠다고 리눅스에게 명시적으로 *알려주는* 것입니다.
지금 해보세요!
