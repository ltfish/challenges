이 모듈에서는 리눅스 파일 경로의 기초를 배웁니다!

리눅스 파일 시스템은 "트리(tree)" 구조입니다.
즉, 루트(root, `/`로 표기)가 있습니다.
파일 시스템의 루트는 디렉터리이고, 모든 디렉터리는 다른 디렉터리와 파일을 담을 수 있습니다.
파일과 디렉터리는 _경로(path)_ 로 가리킵니다.
파일 시스템의 루트에서 시작하는 경로는 `/`(즉, 파일 시스템의 루트)로 시작하며, 그 파일을 찾기까지 내려가야 하는 디렉터리들을 순서대로 나열합니다.
경로의 각 조각은 또 다른 `/`로 구분합니다.
