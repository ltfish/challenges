패턴을 매칭하는 방법이 `grep`만 있는 것은 아닙니다. 때로는 진짜 데이터와 쓰레기 데이터가 같은 줄에 섞여 있어서
쓰레기를 걸러내고 싶을 때가 있습니다. 그럴 때 쓰는 것이 `sed`입니다. `sed`는 텍스트에서 패턴을 다른 단어로
치환하는 간편한 방법을 제공합니다. 매칭하고 치환하는 문법은 간단합니다:

```
sed "s/oldword/newword/g"
```

`s/` - 치환(substitute)  
`oldword` - 바꿀 단어  
`newword` - `oldword`를 대체할 내용  
`/g` - 전역(global, 패턴이 나오는 모든 곳을 찾습니다)  

이 챌린지에서 `/challenge/run`은 플래그를 출력하는데, 각 문자 사이에 "FAKEFLAG"라는 문자열이
끼어 있습니다. 여러분이 할 일은 플래그에서 쓰레기 데이터를 걸러내는 것입니다. 행운을 빕니다!
