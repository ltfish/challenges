이제 _분리(detach)_ 의 마법을 파고들어 봅시다!

원격 접속으로 중요한 작업을 하고 있는데 연결이 끊겼다고 상상해 보세요.
(이 멋진 도장 환경 바깥의) 평범한 터미널이라면 모든 것이 사라집니다.
screen을 쓰면 작업은 계속 돌아가고, 나중에 _다시 붙을_ 수 있습니다!

일부러 _분리_ 할 수도 있는데, 이 챌린지에서 그것을 해봅니다.
`Ctrl-A`를 누른 다음 `d`(**d**etach)를 눌러 분리합니다.
그러면 세션은 백그라운드에서 계속 돌아가고 여러분은 원래 터미널로 돌아옵니다.

```console
hacker@dojo:~$ screen
[doing some work...]
[Press Ctrl-A, then d]
[detached from 12345.pts-0.hostname]
hacker@dojo:~$ 
```

다시 붙으려면(**r**eattach) `screen`의 `-r` 인자를 씁니다:

```console
hacker@dojo:~$ screen -r
```

이 챌린지에서 해야 할 일은 다음과 같습니다:

1. screen을 실행합니다
2. 거기서 분리합니다.
3. `/challenge/run`을 실행합니다(분리된 세션으로 몰래 플래그를 보냅니다!)
4. 다시 붙어서 상품을 확인합니다

----
**재미있는 사실:**
`Ctrl-A`는 기본 설정에서 `screen`의 모든 단축키를 여는 활성화 키입니다.
`screen`의 모든 기능은 `Ctrl-A`로 시작하는 조합으로 실행됩니다.

**힌트:**
기억하세요. Ctrl을 누른 채 A를 누르고, 둘 다 뗀 다음 d를 누릅니다.

**힌트:**
`[detached from...]`이 보이면 제대로 한 것입니다!
