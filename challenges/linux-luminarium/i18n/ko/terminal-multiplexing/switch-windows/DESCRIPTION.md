자, 여기까지 보면 `screen`은 그저 터미널 속의 터미널 같은 이상한 물건일 뿐입니다.
하지만 훨씬 더 많은 것을 할 수 있습니다!

하나의 screen 세션 안에는 브라우저에 탭이 여러 개 있듯 윈도우를 여러 개 둘 수 있습니다.
서로 다른 작업을 정리하는 데 아주 편리합니다!

이 윈도우들은 모두 `Ctrl-A`로 시작하는 여러 키보드 단축키로 다룹니다:

- `Ctrl-A c` - 새 윈도우 만들기
- `Ctrl-A n` - 다음 윈도우  
- `Ctrl-A p` - 이전 윈도우
- `Ctrl-A 0` ~ `Ctrl-A 9` - 0~9번 윈도우로 바로 이동
- `Ctrl-A "` - 모든 윈도우의 선택 메뉴 띄우기

이 챌린지에서는 윈도우가 둘인 screen 세션을 준비해 두었습니다:

- 0번 윈도우에는... 음, 가서 직접 확인해 보세요!
- 1번 윈도우에는 환영 메시지가 있습니다

`screen -r`로 세션에 붙은 다음, 위의 키 조합 중 하나로 1번 윈도우로 이동하세요.
가서 그 플래그를 가져오세요!
