바로 뛰어들어 봅시다!

`screen`은 터미널 안에 가상 터미널을 만들어 주는 프로그램입니다.
브라우저 탭을 여러 개 두는 것과 비슷한데, 커맨드 라인용이죠!

screen을 시작하는 것은 아주 간단합니다:

```console
hacker@dojo:~$ screen
```

그게 전부입니다!
이제 여러분은 screen 세션 안에 있습니다.
겉보기에는 터미널과 _똑같지만_, 발견되기를 기다리는 새로운 기능들이 있습니다.

이 챌린지에서는 screen을 실행하기만 하면 플래그를 얻도록 해 두었습니다.
쉽죠!

----
**참고:**
커맨드 라인을 다 썼으면 `exit`를 입력하거나 `Ctrl-D`를 눌러 screen 세션을 빠져나오세요.
그러면 screen이 종료되고 _원래_ 셸로 돌아갑니다.
