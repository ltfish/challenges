tmux에서 윈도우를 오가는 법을 배워봅시다!

screen과 마찬가지로 tmux에도 윈도우가 있습니다.
키 조합은 다르지만 개념은 같습니다:

- `Ctrl-B c` - 새 윈도우 만들기
- `Ctrl-B n` - 다음 윈도우  
- `Ctrl-B p` - 이전 윈도우
- `Ctrl-B 0` ~ `Ctrl-B 9` - 0~9번 윈도우로 바로 이동
- `Ctrl-B w` - 보기 좋은 윈도우 선택 화면 띄우기

tmux는 아래쪽 상태 표시줄에 윈도우를 이렇게 보여줍니다:
```
[0] 0:bash* 1:bash
```

`*`는 현재 윈도우를 나타내고, 각 항목은 그 윈도우가 실행하려고 만들어진 프로세스도 함께 보여줍니다.

윈도우가 둘인 tmux 세션을 만들어 두었습니다:
- 0번 윈도우에 플래그가 있습니다!
- 1번 윈도우에는 따뜻한 환영 인사가 있습니다.

가서 그 플래그를 가져오세요!
