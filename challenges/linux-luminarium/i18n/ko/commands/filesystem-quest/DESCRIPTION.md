`cd`, `ls`, `cat`을 알게 되었으니, 이제 작은 게임을 하나 해봅시다!

`/`에서 시작합니다.
보통은 이렇습니다:

```console
hacker@dojo:~$ cd /
hacker@dojo:/$ ls
bin   challenge  etc   home  lib32  libx32  mnt  proc  run   srv  tmp  var
boot  dev        flag  lib   lib64  media   opt  root  sbin  sys  usr
```

내용이 정말 많죠!
언젠가는 이것들이 아주 익숙해지겠지만, 지금도 `flag` 파일과 `challenge` 디렉터리는 알아볼 수 있을 것입니다.

이 챌린지에서는 *플래그를 숨겨* 두었습니다!
여기서는 `ls`와 `cat`으로 제가 뿌려둔 빵부스러기를 따라가 플래그를 찾아야 합니다!
방법은 이렇습니다:

0. 첫 번째 단서는 `/`에 있습니다. 그곳으로 가세요.
1. `ls`로 둘러보세요. HINT나 CLUE, 혹은 그 비슷한 이름의 파일이 있을 겁니다!
2. 그 파일을 `cat`해서 단서를 읽으세요!
3. 단서가 말하는 대로 다음 디렉터리로 가세요(아닐 수도 있고요!).
4. 단서를 따라가 플래그에 도달하세요!

행운을 빕니다!
